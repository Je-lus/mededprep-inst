  <action>
1. Add `import { useTheme } from '@/contexts/ThemeContext';` and `import type { ITheme } from 'survey-core';` at the top of TakeAssessment.tsx.

2. Call `const { theme } = useTheme();` at the component top level (NOT inside handleStart — React hook rules).

3. Define two theme objects as constants OUTSIDE the component (module-level) to avoid re-creation:

```typescript
const glassPurpleTheme: ITheme = {
  colorPalette: 'dark',
  cssVariables: {
    '--sjs-primary-backcolor': '#7c3aed',
    '--sjs-primary-backcolor-light': 'rgba(124, 58, 237, 0.1)',
    '--sjs-primary-backcolor-dark': '#6d28d9',
    '--sjs-primary-forecolor': '#ffffff',
    '--sjs-general-backcolor': '#1a0a2e',
    '--sjs-general-backcolor-dim': '#150826',
    '--sjs-general-backcolor-dim-light': '#1e0d35',
    '--sjs-general-forecolor': 'rgba(255, 255, 255, 0.91)',
    '--sjs-general-forecolor-light': 'rgba(255, 255, 255, 0.55)',
  },
};

const daylightTheme: ITheme = {
  cssVariables: {
    '--sjs-primary-backcolor': '#1b5fd0',
    '--sjs-primary-backcolor-light': 'rgba(27, 95, 208, 0.1)',
    '--sjs-primary-backcolor-dark': '#1550b5',
    '--sjs-primary-forecolor': '#ffffff',
  },
};
```

NOTE: The exact Glass Purple primary color hex may need to match whatever Phase 1/2 defined for `--primary` under `[data-theme="glass"]`. If the value is different from `#7c3aed`, read it from the Phase 1 CSS variables and update accordingly. The `--sjs-general-backcolor` values should match the Glass Purple body background tones.

4. Inside `handleStart()`, after the `new Model(parsedSurvey)` call and before any existing `model.applyTheme()` call, replace the existing theme application with:

```typescript
model.applyTheme(theme === 'glass' ? glassPurpleTheme : daylightTheme);
```

If there is already a `model.applyTheme()` call that sets brand colors, REPLACE it with the conditional above (the daylightTheme object includes the same brand primary variables).

5. Do NOT add a useEffect that watches theme changes — the theme is applied once at model creation. If a user switches theme mid-assessment, that edge case is acceptable.

6. Verify the existing `.sd-root-modern * { border-color: revert; }` block in `app/src/index.css` is untouched — do NOT modify index.css in this task.

AVOID:

- Calling useTheme() inside handleStart (hook rules violation)
- Setting colorPalette: "dark" without cssVariables (gives green SurveyJS defaults)
- Adding useEffect for theme re-application on survey model
