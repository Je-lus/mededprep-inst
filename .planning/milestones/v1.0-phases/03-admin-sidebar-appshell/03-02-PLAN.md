  <action>
Create `app/src/components/AppShell.tsx` as the new admin layout component. This replaces `AdminLayout.tsx` entirely.

**Architecture:** Two parallel sidebar trees (research Pattern 1). The desktop sidebar is a fixed `<aside>` with `hidden md:flex`. The mobile sidebar is a controlled `Sheet` that opens from the left. They SHARE the same `<AdminSidebar>` component.

**Imports:**

```tsx
import { useState } from 'react';
import { Outlet } from 'react-router-dom';
import { Menu } from 'lucide-react';
import { Button } from '@/components/ui/button';
import { Sheet, SheetContent, SheetHeader, SheetTitle } from '@/components/ui/sheet';
import AdminSidebar from '@/components/AdminSidebar';
```

**Component:**

```tsx
export default function AppShell() {
  const [mobileOpen, setMobileOpen] = useState(false);

  return (
    <div className="flex min-h-screen bg-background">
      {/* Desktop sidebar — fixed, hidden on mobile */}
      <aside className="fixed inset-y-0 left-0 z-20 hidden w-64 md:flex md:flex-col">
        <div className="sidebar-glass flex h-full flex-col bg-card">
          <AdminSidebar />
        </div>
      </aside>

      {/* Mobile sidebar — Sheet drawer from left */}
      <Sheet open={mobileOpen} onOpenChange={setMobileOpen}>
        <SheetContent side="left" className="w-64 p-0">
          <SheetHeader className="sr-only">
            <SheetTitle>Navigation</SheetTitle>
          </SheetHeader>
          <div className="sidebar-glass flex h-full flex-col bg-card">
            <AdminSidebar onNavigate={() => setMobileOpen(false)} />
          </div>
        </SheetContent>
      </Sheet>

      {/* Main content area with sidebar offset */}
      <div className="flex flex-1 flex-col md:pl-64">
        {/* Mobile header with hamburger — hidden on desktop */}
        <header className="sticky top-0 z-10 flex items-center gap-4 border-b bg-background px-4 py-3 md:hidden">
          <Button variant="ghost" size="icon" onClick={() => setMobileOpen(true)}>
            <Menu className="h-5 w-5" />
            <span className="sr-only">Open menu</span>
          </Button>
          <span className="font-semibold text-foreground">MedEdPrep</span>
        </header>

        {/* Page content */}
        <main className="mx-auto w-full max-w-7xl flex-1 px-6 py-8">
          <Outlet />
        </main>
      </div>
    </div>
  );
}
```

**Critical implementation details:**

1. **DOM structure for glass blur:** The `<aside>` has `position: fixed` and `z-20`. The `sidebar-glass` class is on an INNER `<div>`, NOT on the `<aside>` itself. This avoids the stacking context trap (research Pitfall 1): if `backdrop-filter` were on the same element as `position: fixed`, child elements' `position: fixed` would break.

2. **z-index strategy:**
   - Desktop sidebar aside: `z-20` — above content, below mobile Sheet (which renders at shadcn's default `z-50` via portal)
   - Mobile header: `z-10` — above scrolling content
   - The mobile hamburger trigger is `md:hidden` so it never shows on desktop

3. **`sidebar-glass` class placement:** Applied to BOTH the desktop sidebar inner div and the mobile Sheet inner div. In Daylight theme, this class has no CSS effect (no `[data-theme='daylight'] .sidebar-glass` rule). In Glass Purple, the CSS from Plan 01 activates the blur.

4. **`bg-card` fallback:** Both sidebar containers have `bg-card` as a Tailwind fallback. In Daylight, `bg-card` is white (the card CSS variable). In Glass Purple, the `.sidebar-glass` CSS rule overrides with `rgba(255,255,255,0.05)`.

5. **Mobile Sheet accessibility:** `<SheetHeader className="sr-only"><SheetTitle>Navigation</SheetTitle></SheetHeader>` provides the required accessible title for the Radix Dialog underlying Sheet (research Pitfall 6).

6. **Content area:** `<main>` has `mx-auto max-w-7xl px-6 py-8` — matching the current `AdminLayout.tsx` main content area styling so existing pages look identical.

7. **No ThemeToggle in AppShell:** The toggle lives inside `AdminSidebar` (Plan 01). On mobile, users open the Sheet to access it. This matches the research recommendation (Open Question 3).

Export as default.
